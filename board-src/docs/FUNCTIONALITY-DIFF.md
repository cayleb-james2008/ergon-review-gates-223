- Search match count shows in the status line and, at zero, an overlay 'No jobs match.' on the board; there is no per-line count and no visible per-line job count.
- A failed status-select change reverts silently with no visible error message (O-051).
- Clicking the card body or note when unlocked does not open the dialog; only the title text is the hit target, which is a small target on a wall-mounted or touch screen.
- Stale passcode shows as unlocked after reload until the first write is rejected (tab shows Lock and the Add job button even though the stored code is wrong).
- Delete is only inside the edit dialog (two-step). There is no undo.
- Status 'Done' and 'Open' pills are the same grey, so Done is told apart only by the check icon and the struck-through title.
- Skeleton blocks in the loading state have no shimmer animation (animationName none).
- Print: one landscape Letter page with logo dark variant and bubble hidden, but the printed 'Test data' chip and live text remain in the header.

- Moving a job to another line is only possible through the Edit dialog Line dropdown; no drag-and-drop between lines, no reordering within a line (order is created_at only).
- No clear-line, bulk status change, bulk delete or undo; delete is only per job via two-step confirm in the dialog.
- No keyboard shortcuts: '/' does not focus search and 'n' does not open Add job (tested with focus on the page).

- Passcode is stored raw in sessionStorage under rhl.edit (this tab only) while unlocked.
- Rows shrink noticeably when a banner is shown (row ~35px at 1080 with banner) and cards switch to the single-line layout; no scrolling introduced.
